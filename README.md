# МАЙСТЕРНЯ — офлайн-архів столярних креслень

Готовий мобільний сайт-каталог у стилі яскравих карток: **без LEGO, без платних сервісів, без зовнішніх бібліотек та без залежності від інтернету**.

## Що всередині

- **10 твоїх вихідних PDF** з усіма оригінальними сторінками, кресленнями, специфікаціями та інструкціями; **74 сторінки разом**.
- Кольорові картки з ілюстраціями, взятими з твоїх PDF.
- Пошук по назвах, розмірах та тегах.
- Теми: Меблі / Сад / Для дому / Ремонт.
- Улюблені та «Позначити як виготовлений» (зберігаються у браузері цього пристрою).
- Перегляд кількох сторінок без окремого PDF-програвача; оригінальний PDF можна відкрити повністю.
- Офлайн-режим на GitHub Pages (Service Worker + кеш).
- Адаптація під iPhone 17 / інші телефони / комп'ютери.

## Запуск без інтернету на ПК

1. Розпакуй ZIP повністю (з підпапками `assets/` і `pdfs/`).
2. Відкрий **`index.html`** у будь-якому сучасному браузері.
3. Усі креслення вже поруч у `pdfs/` — мережа не потрібна. Деякі браузери можуть обмежувати функції локального сховища при `file://`, але пошук і PDF працюють.

## Розміщення на GitHub Pages

1. Створи новий репозиторій на [github.com/new](https://github.com/new), наприклад `maisteria-archive`.
2. Розпакуй ZIP та **завантаж вміст папки** (файли `index.html`, `style.css`, `app.js`, `catalog.js`, `sw.js` тощо, включно з `pdfs/` і `assets/`) у корінь репозиторію. **Не** завантажуй ZIP як один файл.
3. Зроби Commit changes.
4. У репозиторії вибери **Settings → Pages**.
5. У полі **Build and deployment** встанови **Deploy from a branch**, **main**, **/(root)** і натисни Save.
6. GitHub покаже посилання на сайт виду `https://ТВІЙ-АКАУНТ.github.io/maisteria-archive/`.
7. Відкрий сайт онлайн та **дочекайся напису «Офлайн готово»** у жовтій панелі. Тоді автономний кеш має бути підготовлений.
8. Для iPhone: відкрий сайт у **Safari → Поділитися → На Початковий екран**. Збереження кешу залежить від налаштувань Safari та вільного місця; не очищай дані сайту, якщо потрібен офлайн-доступ.

**УВАГА:** у відкритому репозиторії GitHub усі 10 PDF доступні всім за посиланням! Для приватного особистого архіву краще тримати локальний ZIP або вибирати інший приватний спосіб розміщення.

## Як додати власне креслення

1. Скопіюй, наприклад, файл `my-table.pdf` у папку `pdfs/`.
2. Додай картинку-обкладинку `assets/my-table.webp` (можна й `png` або `jpg`).
3. Відкрий `catalog.js` і додай ще один об'єкт **усередині масиву `PROJECTS`**, перед кінцевим `];`. Приклад:

```js
{
  id: 'my-table',
  title: 'Мій стіл',
  subtitle: 'Новий проєкт',
  category: 'Меблі',
  dim: '1000 × 600 × 750 мм',
  description: 'Мої креслення дерев’яного столу.',
  tags: ['стіл', 'майстерня'],
  colors: ['#FFD77D', '#F0AD58'],
  cover: 'assets/my-table.webp',
  pdf: 'pdfs/my-table.pdf',
  pages: 5,
  previews: []
},
```

4. Зміни текст лічильника `10 PDF` у `index.html` (за потреби) й у `sw.js` додай нові файли до масиву `ASSETS` та підвищ версію `CACHE_NAME` (наприклад, `v1` → `v2`), щоб вони теж гарантовано працювали офлайн.

## Структура

```text
index.html            головна сторінка
style.css             кольори, картки, адаптація
app.js                пошук, фільтри, картки та вікна
catalog.js            список твоїх проєктів
sw.js                 офлайн-кеш
manifest.webmanifest  параметри для додавання на головний екран
assets/               іконки, вирізані ілюстрації та прев'ю сторінок
pdfs/                 10 оригінальних креслень PDF
```

## Обмеження

- Це **статичний** сайт. Зміни улюблених/готових виробів зберігаються лише на конкретному пристрої й не синхронізуються з GitHub.
- У користувацькому інтерфейсі не передбачене завантаження PDF у репозиторій: для цього треба додати файли та запис у `catalog.js`.
- Це довідковий архів, не система інженерної перевірки міцності. Перед виготовленням та особливо після пошкоджень вибуховою хвилею перевір матеріали, несучі конструкції та безпечність монтажу.
