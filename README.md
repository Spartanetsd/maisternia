# Майстерня: Точний різ 🪚

**Безкоштовна українська офлайн-гра** про столярне ремесло, логіку та економний розкрій деревини. Відкрий 12 замовлень, плануй використання дошок і збирай до 36 зірок.

## Запуск

- **На ноутбуці:** відкрий `index.html` у браузері. Інтернет не потрібен.
- **На телефоні:** відкрий опубліковану адресу GitHub Pages. Для надійної офлайн-роботи після першого завантаження додай сайт на головний екран. На iPhone: Safari → Поділитися → «На початковий екран».
- **Збереження:** рекорди та прогрес зберігаються лише в браузері пристрою (`localStorage`), не передаються на сервер.

## Як грати

1. Обери дошку, з якої різатимеш деталь.
2. Обери потрібний розмір деталі.
3. Натисни **«Зробити різ»**.
4. Враховуй **пропил 3 мм** на кожен різ (крім випадку, коли деталь дорівнює всій заготовці).
5. Зроби всі потрібні деталі, мінімізувавши витрати деревини. Якщо застряг — **«Підказка»**, **«Скасувати різ»** або **«Почати заново»**.

Три зірки можна отримати за високу ефективність розкрою без додаткових дощок. Придбання додаткової дошки в грі допомагає завершити рівень, але знижує максимум оцінки до 1 зірки.

## Публікація на GitHub Pages

1. Створи новий **публічний репозиторій** на [github.com/new](https://github.com/new), наприклад `maisternia-game`.
2. Завантаж у корінь репозиторію **всі чотири файли** з цього пакета: `index.html`, `icon.svg`, `manifest.webmanifest`, `sw.js`. `README.md` також можна завантажити.
3. У репозиторії відкрий **Settings → Pages → Build and deployment**.
4. **Source: Deploy from a branch**, **Branch: main / (root)**, потім **Save**.
5. Після публікації гру можна відкрити за адресою `https://ВАШ-ЛОГІН.github.io/maisternia-game/`.

> Назва репозиторію може бути іншою — тоді в адресі буде інша назва. GitHub може потребувати деякого часу на публікацію. Жодних токенів доступу в коді немає.
