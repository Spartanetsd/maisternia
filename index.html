Як читати креслення?

Відкрий картку виробу та натисни «Відкрити PDF». Оригінальна інструкція містить креслення, розкрій, матеріали та порядок складання. Під карткою є добірка сторінок для швидкого перегляду.

Як працює офлайн?

У ZIP уже є усі PDF, картинки та код. Якщо розпакувати його на комп'ютері, index.html працює без інтернету. На GitHub Pages достатньо один раз відкрити сайт онлайн і дочекатися повідомлення «Офлайн готово».

Як додати на iPhone?

Відкрий сайт через Safari → «Поділитися» → «На Початковий екран». Після першого повного завантаження документи будуть доступні офлайн за умови збереження даних Safari.

Як додати новий PDF?

Поклади його в папку pdfs та додай запис до catalog.js. Інструкція наведена в README.md всередині архіву.

Увага: якщо опублікувати сайт у відкритому репозиторії GitHub, усі PDF теж будуть публічними.
